# task: 采纳 NLR 0.16.1（微卡）

你是执行者。`narraleaf-react@0.16.1` 已发布上 npm（`latest`）。它修掉了 0.16.0 迁移时被迫绕开的两个引擎缺陷，本卡把 Studio 侧的两处权宜之计拆掉。

前置阅读：`docs/plans/reports/2026-07-24-nlr-0-16-report.md`（§停机裁决记录了两处绕障的全部背景与判据）；M3 卡 `2026-07-23-001` §0 纪律与 §1 风格铁律**原样适用**（逐文件 `git add`，共享检出上有其他 session 的 WIP，禁 `git add -A`、禁 stash）。分支：从 develop（`6e1a5d1`+）切 `feat/story-adopt-0-16-1`。报告：`docs/plans/reports/2026-07-24-adopt-0-16-1-report.md`（≤40 行，模板同前）。

## WI-1 升级依赖

`package.json` 的 `narraleaf-react` `^0.16.0` → `^0.16.1`，`yarn install` 更新 lockfile。确认解析到 0.16.1（`Darkness` 已在公开导出、`Push` 的 `translate` 产出 `%` 而非 `vw`/`vh`）。

## WI-2 `slide` 切回 native `Push`，删除 `Slide`

- 背景：0.16.0 的 native `Push` 用 `vw`/`vh` 平移，而转场层是 `inset:0` 的信箱盒，窗口比 ≠ 设计比时溢出露背景；Studio 因此**保留了自带的 `Slide`**（`src/renderer/lib/ui-editor/runtime/game/transitions/customImageTransitions.ts`，唯一幸存的自定义转场）。0.16.1 已把 `Push` 改成按 `%` 平移，数学与 Studio `Slide` 逐行等价（独立复核结论：四方向 × 进出两相、解析盒子都一致，切换后视觉应当像素级相同）。
- 做：`createTransition`（`storyCompiler.ts`）的 `slide` 分支改用 native `Push`（构造形态是 options 对象，与 `Slide` 的位置参数不同，照 0.16.1 的 `PushOptions` 写）；删除 `Slide` 类。**若 `customImageTransitions.ts` 因此只剩空壳或无意义的残留，整个文件连同其测试一并删除**（不要留一个只导出常量的空文件）；若仍有其他仍在使用的导出，保留并说明。
- `StoryTransitionRef.kind` 的 `slide` 值与 stored props **不变**（既有项目零迁移）——这是硬要求，用测试锁定。

## WI-3 接通 `darkness`

- 背景：`darkness` 是 bible §1.3 词表里的合法规范值，但 0.16.0 未导出 `Darkness`，迁移时保留了规范值 + 编译期显式诊断（且此前一直是 no-op）。0.16.1 已导出 `Darkness` + `DarknessOptions`。
- 做：`createTransition` 的 `darkness` 分支改为真正构造 `Darkness`；移除那条"无公开等价物"的诊断；`bible §1.3` 表格里 `darkness` 行的 ⚠️ 标记与脚注同步撤掉（**bible 是立法文本，改它要连同表格一起改准确**）。
- 检查器（`TransitionEditor`）为 `darkness` 补参数控件与默认值——形态复用既有转场的控件惯例，参数与默认值取 `DarknessOptions`（读 0.16.1 的 d.ts / CHANGELOG 条目为准，不要猜）。i18n en+zh。

## WI-4 回归

`slide` 与 `darkness` 之外的转场行为**零变化**：编译器集成测试全绿，既有 `t=` 规范值的产物形状不变（新增/更新断言锁定 `slide`→`Push`、`darkness`→`Darkness`）。

## 验证与停机

`yarn lint` 全绿；vitest 新失败 0（win32 基线 8 个列名即可）。真机：`/bg t=slide` 在**非设计比窗口**下确认不露背景（这是本卡的关键验收——它验证 0.16.1 的修复真的生效，也是当初保留 `Slide` 的唯一理由）、`/bg t=darkness` 观感与参数可调、任取两三个其他转场确认无回归；截图存 `docs/plans/reports/assets/`。停机：native `Push` 在真机上仍溢出（说明 0.16.1 的修复不完整 → 报告实例，恢复 `Slide` 并交 orchestrator）；`Darkness` 的公开参数与检查器现有控件语言无法对齐；`slide` 的 stored props 无法保持不变。
