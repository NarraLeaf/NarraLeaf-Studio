## 偏离与决策
- **打包三数按卡内定义**：`Difference = Actual − Predicted`，因此非资产字节（metadata json、陈旧 content）落在差额里。同时把 Unreferenced 字节独立列出，读者自己能看出两者的间隙就是"非资产/陈旧字节"——不写解释性文字。真机上二者都是 11.4 MB，间隙可忽略。
- 措辞只用 Actual / Predicted / Difference 这类**字段名**，无动词、无"将节省"，不会读成已生效。
- 未做 session 序列化（关窗后 tab 不恢复）——与 scene-flow tab 现状一致，且卡未要求，不动 `workspaceEditorSession.ts`。
- 刷新收敛：快照自身的 `ensureReady`/`flush` **会发 index-changed**，直接监听会自激。改为"运行中到达的变更只记账、结束后至多再跑一次"（第二遍无待 flush 项→不再发信号，必收敛），既不死循环也不丢真实编辑。
- i18n 挂在既有 `assets.overview.*` 而非新命名空间：少动 en/zh index，且语义归属正确。WI-2 零新词条（复用 `containerHeader.else/option`）。

## 风险与已知
- `walkDirectoryBytes` 是 per-file IPC：万级资产项目首屏会明显变慢（并发 16 + 仅 `active` 时跑 + 变更事件失效）。若成为问题，正解是主进程加一个递归 size IPC，而不是抽稀采样。
- 页面按 `assets/` 整目录计 Actual；若将来打包范围变了，这个左值要跟着改，否则口径会分叉。
- 边 label 22 字截断后无 tooltip（React Flow 边 label 不便挂 title），长选项文本只能看开头。

## 重点验收（用户手测）
1. 在资产量更大的真实项目里开总览：数字与侧栏/属性面板对齐、首屏耗时是否可接受。
2. 打包措辞复核：Actual / Predicted / Difference 三个数是否**确实不会**被读成"裁剪已生效"。
3. 自己写的 if/choice 分支（含 elseIf、未设条件的分支）在流程图上的 label 是否读得懂；`sequence`/`repeat` 内的 jump 确认为实线。
