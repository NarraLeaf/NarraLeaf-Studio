## A1 类型闭环：**咬住了**（卡的第一个问题）

新增 `vfx` 这个 kind 时 `tsc` 先失败在 `storyCommandCategories.ts:134`——`subjectGroupId` 拒绝返回一个不存在的 group id，直到「氛围特效」以完整 icon+色值进 `STORY_COMMAND_GROUPS`；随后钉值表（`Record<StoryCommandGroupId,string>`）又强制把 hex 写下来。另有三处一起失败：`/show`的 stage dispatch、`displayableTargetRef`、`collectStageObjects`。**这不是障碍而是设计**，四处都是必须表态的地方。A1 无缺陷可报。

## 落点与设计决定

- **`/rename`**：`operation:"setName"` + `displayName`。检查器只给「角色 + 显示为」两格——改名不碰立绘，给它变换/外观/转场等于给出编译永远不读的字段。行摘要 `Rename Alice → ？？？`（名字就是这行的全部内容）。
- **video 四操作**：只加 `/seek` 一个 token；`/stop` `/pause` `/resume` 的 `accepts` 加 `video` 后按解析结果分派（B3），无目标仍是 BGM（B4）。`seek` 的 payload 存 ms，引擎收 s，边界处换算并 floor 到 0。
- **`/vfx`**：`create` 既构造又注册名字（video 的形状），show/hide/pause/resume/setRate 全部靠既有泛型动词。`/stop` **故意不接** vfx——`Vfx` 没有 stop；`/rate` 接 vfx 不接 video（video 没有 rate）。混合模式按**素材路线**命名（透明素材 / 黑底辉光 / 白底阴影），不写教程段落。
- **`/label` `/goto`**：两条编译期 `error` 诊断（跨行不存在的标签、同场景重名），因为这两种形状会让引擎 `Story.build` 抛错而作者拿不到出错的行。`/goto` 的目标是**新 param kind `label`**，候选来自与编译器同一份扫描（`shared/types/story/labels.ts`），所以「菜单给过的名字一定能 build」是结构性的而不是巧合。两者都不是容器（`canAcceptChildren` 排除），各有徽标与行摘要。

## 偏离与需要点名的事

1. **`create` 没有进 `displayableSourceIdentity`**（卡 §WI-1 点名要求）。该函数返回 `StoryDisplayableTargetKind`，而那个类型按设计**排除**非 Displayable；把 vfx 塞进去会让它出现在 `/transform` `/fx` 的目标选择器里——正是同一条 WI 明令禁止的事。改走 **video 已有的那条路**：`collectStageObjects` 直接扫场景块。目标解析因此照样找得到 vfx（测试逐条断言），卡的**意图**满足，**机制名**是错的。这不触发「与既有 `displayableSourceIdentity` 冲突」的停机条件：没有冲突，只有卡面误指。
2. **`targetParam` 新增 `fallbackKind`**（超出卡面的一处机械）。给 `/stop` 加 `video` 会连带毁掉 `/stop hit` 这类自由名字（两种 kind 就无从分派），而那是既有能力。`fallbackKind` 在 param 上写明「认不出的名字算哪一界」，resolution 与候选层读同一条规则。不这么做就得默默缩小作者的写法。
3. **候选按 kind 加副标**：跨界的目标槽（`/stop` `/pause` `/show`）每个候选带 `audio`/`video`/`vfx` 字样。这是卡里「ghost 提示要显示将要作用的对象」的落地——ghost 本身只报槽位名（`<target>`），真正会误导人的是候选列表里 "intro" 看不出是视频。规则读 `accepts`，无指令特例。
4. **`/show clip t=fade` 这类词在 video/vfx 上仍被静默丢弃**（既有 papercut，vfx 只是并入）。reveal/conceal 预设表根本不描述非 Displayable，对着它报错是报错了错误的东西。未扩大，也未修。
5. `ActionCommandId` 未为三个新指令增长：`/rename` `/vfx` `/label` `/goto` 都在 spec 内联建块，沿用 A2 `/camera` 的先例——那张 union 是退役目录的残留。
