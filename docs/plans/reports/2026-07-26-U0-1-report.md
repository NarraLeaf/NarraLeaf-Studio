## 实现要点

- **一个变量、一条规则**：`lib/appearance` 把 `--nl-editor-surface-opacity` 发到根元素，`.nl-editor-surface { background-color: rgb(var(--nl-surface-sunken) / var(--nl-editor-surface-opacity)) }` 是唯一消费点；三个组件只换 class。`editorSurfaceAlpha()` 在两端发字面量 `"1"` / `"0"`，不是 0.99/0.01。
- **偏离卡面一处（更强不是更弱）**：卡里写"沿用 `storyEditorTextStyle.tsx` 的 getGlobalState + focus 重读"。实际挂在 `initAppearance` 上——同样是 `getGlobalState`，但**首帧前读 + 订阅 `onGlobalStateChanged`**，于是"改完立刻生效"对**每个窗口**成立（含 Dev Mode，focus 范式跨窗口做不到）。零新机械。
- Dev Mode 面板 tab 条去掉了自己那份 `bg-surface-sunken`：它是面板根的直接子元素、同一 token，留着会在 <100% 时把 alpha 叠一遍叠出新接缝。100% 时逐像素等价。
