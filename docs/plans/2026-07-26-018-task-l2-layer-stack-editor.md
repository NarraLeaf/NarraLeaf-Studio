# L2 层栈编辑器

母卡 `2026-07-26-013` §5「L2」。前置 L0（引擎 0.18.0）+ L1（模型/迁移/消费面）已并入 develop
`8465609e`，L1 的目视验收补做完毕，结果与缺陷记在 `2026-07-26-015` §4.5。

现状一句话：**能建能看，不能改**。L1 的编辑器是最小实现——层能加能删能绑轴能配图，
但改名、重排、显隐、诊断一概没有，而且**建 layered 角色这条路本身就没通**（F2）。
本卡把它补成一个真的层栈编辑器。

## 1. 本卡先收 L1 验收欠下的四条

这四条不是"顺手带上"，是 L2 的前提——没有 F2 就没人能走到这个编辑器里来。

- **F2 建档入口**：`CharacterPanel.handleCreateCharacter` 永远只传 name。新建角色时
  二选一（预合成 / 分层）。**不做**冷切换 UI：母卡裁决允许改档，但改档要清空外观 +
  二次确认 + 先报受影响故事行数，那是独立一张卡（`setKind` 服务层已就绪）。
- **F3 改名与删 tag**：`rename` / `removeTag` 在 UI 里没有调用方。pose / 轴 / tag / 层
  全部要能改名，tag 要能删。
- **F4 属性面板分档**：layered 角色不再渲染「默认姿态」下拉；换成该档有意义的东西
  （画布尺寸 + 每轴默认 tag）。
- **风格债**：L1 的图标按钮全用 `title=`，而本仓的规矩是编辑面**不用原生 tooltip**
  （盖住正要点的像素）。一律换成 `aria-label`。

（F1 的 `{{name}}` 插值与 F5 的硬编码英文告警，走 §6 那张微卡，不占本卡。）

## 2. 层栈：从"列表"变成"栈"

层项现在是一张只有名字和轴下拉的卡。目标形态，自下而上读**存储序**、自上而下读**画面序**
（沿用 L1 的反转显示）：

- **拖拽重排**。`draggable` 在本仓是**默认失效**的（`styles.css` 给 `*` 设了
  `-webkit-user-drag: none`），拖拽源必须同时带 `nl-drag-source`，否则 `dragstart` 根本不触发。
  验收必须用**真实鼠标序列**（`Input.dispatchMouseEvent` 按下 → ~20 步小位移 → 释放），
  合成 `DragEvent` 会在功能完全坏掉的情况下照样通过。服务层 `moveLayer(layerId, toIndex)` 已有，
  UI 只需给出落点。
- **每层缩略图**：显示该层在**当前预览 tag** 下实际画的那张图（`options[tags[axisId]]`），
  没有就是"不绘制"。这比"image set"三个字有用得多。
- **显隐与锁定，都是编辑期状态，不入数据**。母卡写死了这条。当前实现把 `hidden` 存进了
  `CharacterLayer` **并且** `toLayeredDefinition` 会跳过它——等于隐藏一层就改了游戏输出，
  这是个隐蔽的坑。本卡把 `hidden` 从持久化模型和 `toLayeredDefinition` 里**摘掉**，
  改成编辑器组件状态（顺带 `setLayerHidden` 一并删）。锁定同样只是编辑期：锁住的层不能拖、
  不能改图、不能删。
- **轴↔层双向高亮**：点轴高亮它驱动的层，点层高亮它的轴。不加新控件，用现有选中态。

## 3. 轴面板

- 轴改名、tag 改名、tag 删除、**设默认 tag**（现在只能靠服务层）。
- tag 芯片现在只切预览；要区分"切预览"与"编辑该 tag"两件事——沿用本仓习惯：
  单击切预览，hover 才露出改名/删除的图标按钮。
- 一个轴一行，不堆条。

## 4. 预览面

- **洋葱皮**：把同轴的另一个 tag 以低透明度叠在当前之下，用来对位。开关一个，不做浓度滑块。
- **像素级查看**：复用 `ImagePixelPreview`，缩放沿用舞台预览的 ctrl+滚轮手势，不加缩放条。
- **画布**：`canvas` 现在只能是 `null`（没有任何 UI 写它）。给出「以当前最底层的尺寸设为画布」
  一个动作；设定后头部读数从"第一张图"变成"声明画布"。
- 头像裁剪（`portrait`）：母卡列在 L2，本卡**排在最后做**，做不完就单独一张卡——
  它要在合成结果上框选，而合成服务是 L4 的 `SpriteCompositor`。

## 5. 诊断面板

母卡说"诊断是本档一半的价值"。一个面板，按 error / warning 两级，点一条跳到对应的层或轴：

| 级别 | 诊断 | 判定 |
|---|---|---|
| error | 层尺寸 ≠ 画布 | 已有读数（`LayerStackPreview`），要挪进面板并给出**差值**，不只是尺寸 |
| error | 开关层某个 tag 没图 | `options[tag] == null` 且该层不是有意留空——区分不了就降为 warning，见下 |
| error | 轴没有 tag / 轴不驱动任何层 | 它的 tag 永远到不了引擎（`toLayeredDefinition` 会整层跳过） |
| error | 常量层没图 | 现在会被静默丢弃（`toLayeredDefinition` 只在 url 有值时 push） |
| warning | 同一轴内 tag **显示名**重名 | id 唯一由模型保证，但重名的显示名在选择器里没法认 |
| warning | 层被上面的层完全遮挡 | alpha 求交，离线算一次，缓存到层资产变更 |
| warning | 层资产没有被任何 tag 引用 | 换图后遗留的孤儿 |

「某个 tag 没图」与「这一层在这个 tag 下故意不画」在数据上都是 `null`——母卡的作用域层
（"只有私服有外套"）依赖的正是这个 `null`。所以**不能**一律报 error。本卡的判定：
一个层如果**所有** tag 都是 `null`，那是没配；有的有有的没有，那是作用域层，不报。

## 6. 明确不做

- PSD 导入（L3）、`SpriteCompositor` 与合成缩略图（L4）、组合浏览器与快照（L5）。
- preset↔layered 冷切换向导（单独一卡，见 §1）。
- 层偏移 / 混合模式（引擎 E4，母卡已裁决不做）。
- F1（i18n 插值）与 F5（硬编码告警）→ 单独一张微卡，连带 `characterForm` 语法 token
  改名那笔旧债一起收。

## 7. 判据

沿用铁令：执行者的报告不构成验收，orchestrator 亲手拉起实例、驱动到指定状态、亲自读图。

1. 从角色面板**新建**一个分层角色（不碰服务层），建两轴四层、配图、存盘。
2. 把最上面的层用**真实鼠标拖拽**拖到最下面，预览的叠放顺序随之改变

5. 把一个轴的 tag 改名：预览、选择器、故事行三处显示名同步，行里存的 id 不变。
6. 一个层在部分 tag 下留空（作用域层）：**不报 error**；全部留空：报。
