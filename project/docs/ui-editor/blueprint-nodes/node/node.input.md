# Input 节点

项目给手势起的名字，以及界面对它的回答。一个输入操作有 id、作者读的名字，和一组默认绑定；每个 Surface 再单独说它回不回答、加不加绑定、要不要覆盖掉项目默认的那组。

这套东西存在的意义就是让绑定离开图：作者把「点对话框 = 推进」从单击改成空格，改的是词表里的一行，而不是每一张监听它的图。所以 Input 分类的节点只认操作的名字，从不描述用什么触发。

## Is Action Held

`blueprint.input.isActionHeld` - 指定输入操作当前是否按住

用于长按类手势：按住推进等于快进，松开就停。纯节点，可以直接接进 Blueprint Value 或者绑定引脚，因此也能用来在按住期间改控件的外观。

卡片字段：
- `Action` - 从项目的输入操作词表里选一个（Inspector 参数）。留空时节点恒为 `false`，而不是报错——半填的卡片不该把玩家正在看的界面弄崩

输出：
- `held` - `boolean`。宿主没有输入路由时（例如编辑器预览里根本没有人在按键）读作 `false`，而不是空值

### 「按住」按的是什么

按住是**手上的事实**，不是事件。操作触发一次就完了，事件本身留不下「手还在不在」这条信息，所以运行时另外记着此刻按下的键和鼠标键（`runtime/input/inputHoldState.ts`），`Is Action Held` 拿绑定去对它。

- **绑定按提问的那个 Surface 解析**。它覆盖了项目默认（`overrideBindings`），就按它的；它加了绑定（`addBindings`），加的那些也算；它对这个操作只字未提，就退回项目词表里的默认绑定。一个 Surface 把绑定覆盖成空，等于说「这个手势不归我」——于是这里也读作没按住，和它在那里触发不了任何东西是同一句话。
- **能被按住的是键、鼠标键和长按**。绑到 `longPress` 上的操作在识别器计满 500ms 之后读作按住，手指抬起就结束；在计满之前读作 `false`，否则「按住隐藏对话框」会在每一次轻点上都成立。滚轮是一瞬间的事；双击是一个**序列**而不是一个状态，按着不放并不等于双击正在进行中。绑到 `doubleClick` 和四个 `wheel*` 上的操作永远读作 `false`。
- **`overControls` 照样管用**。指针绑定默认 `skip`，那一下要是按在按钮、开关、滑块、文本框或者列表上，就不算按住——面板级的「按住推进」不该在玩家正按着返回键的时候跑起来。判据取**按下时落在哪**，不是指针现在在哪：从头到尾都是同一次按压，中途拖到哪里都还是它。
- **窗口失焦会清空**。玩家 Alt-Tab 走掉，`keyup` 永远不会来，所以失焦就当全部松开；否则那一次按住会一直「按」到会话结束。

## Get Input Device

`blueprint.input.getDevice` - 玩家当前使用的输入设备

用于同一句话在不同设备上要写成不同措辞：读出设备，分支，各自设置文本。纯节点，可以直接接进 Blueprint Value 或者绑定引脚。卡片上没有字段。

输出：
- `device` - `string`，取值 `pointer` / `key` / `gamepad` / `touch`，与 `On Action` 的 `source` 引脚是同一套值，因此两边用同样的字面量去比。答的是玩家最近用的那件硬件，不是某条绑定能接受什么——只有前者能决定界面该印哪个词。宿主没有输入路由时（例如编辑器预览里根本没有人在操作）读作 `pointer`，而不是空值——作者不必为「设备读不出来」单写一条分支
